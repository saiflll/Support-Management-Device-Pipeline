> System Guide & Pendidikan Makna Bersama

[1] Makna Bersama (Core Philosophy)

Ekosistem Servfor dibangun untuk menjadi single source of truth di lini manufaktur/produksi. Mulai dari menimbang berat pack otomatis (MDCW Forming), memonitor parameter suhu lingkungan & keamanan akses (Door Prox Forwarder), hingga memperbarui firmware hardware di lapangan secara kolektif (OTA Dashboard). Semuanya terajut dalam jala iot-net yang sepenuhnya tertutup, mengandalkan EMQX Broker sebagai sumsum tulang lalu litas datanya.

[2] Pendidikan Flow / Peran Tiap Service

  • forming-app (Port 3000): Bertugas memakan ribuan log MQTT setiap detiknya dari timbangan. Disini tertanam Welford ML Algorithm mandiri yang meraba statistik deviasi berat/waktu untuk secara gaib memisahkan data VALID dari data SPAM / ISENG mekanik, sehingga database PostgreSQL Anda tetap bersih tanpa ampas.
  • forwarder-app (Internal Port 8888): Si satpam pintu masuk. Menjalin jembatan dengan Node sensor (Suhu, RH, Akses Pintu). Bahkan ini digunakan murni untuk memblokir Adminer DB UI dari ancaman publik. Jika engineer mau masuk panel DB, forwarder mewajibkannya menebus Kode OTP Telegram terlebih dahulu! Zero-Trust sungguhan.
  • ota-app (Port 9999): Penjaga armada MCU. Ribuan ESP32 tidak perlu lagi di-flash berdarah-darah pakai kabel. Cukup *upload* firmware ke Dashboard, MCU yang rutin menyapa via Port 9999 akan di-intercept. Jika versinya lawas, *binary stream* akan ditembakkan langsung ke hardware di lokasi.

[3] Panduan Eksekusi Lengkap (Deployment)

# 1. Pastikan Anda punya variabel konfidensial dari envi.txt
$ cp envi.txt .env

# 2. Build semua microservice secara simultan menjadi container
$ ./dev/build-and-push.bat

# 3. Jalankan Orkestrasi Database & App 
$ docker compose up -d

# 4. Monitoring Sistem Berjalan
$ docker ps | grep iot-net
$ docker logs -f forming-app
$ docker logs -f forwarder
