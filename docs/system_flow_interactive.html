🚀 Macro Architecture

Sistem ini dirancang dengan arsitektur mikroservis berbasis kontainer. EMQX bertindak sebagai pusat saraf (backbone) untuk semua komunikasi perangkat IoT, sementara Forwarder, OTA, dan Forming menangani logika bisnis, manajemen firmware, dan monitoring produksi secara real-time.

🔐 Multi-Layer Security (Telegram 2FA)

Keamanan database dijamin melalui 4 lapis perlindungan: Telegram Out-of-band 2FA, HTTPOnly Session Cookies, Adminer Reverse Proxy, dan Network Isolation (Adminer & DB tidak memiliki port yang terekspos langsung ke publik).

🌐 Network Topology & Isolation

Semua servis berjalan di dalam subnet Docker 192.168.200.0/24. Hanya servis dashboard yang mengekspos port ke host, sementara PostgreSQL dan Adminer terisolasi total di dalam jaringan internal untuk mencegah akses ilegal.

update 📦 OTA Update Workflow

Alur update firmware: Admin mengunggah file binary ke OTA Dashboard, sistem mengirim notifikasi via MQTT ke perangkat target. Perangkat kemudian mengunduh file secara aman via HTTP Stream dan melaporkan progres kembali ke dashboard secara real-time.
